# m_k_chart 2.0 Phase 3 指标缓存性能基线

> 任务：P3-02  
> 日期：2026-08-25  
> 环境：macOS、Flutter 3.44.0、Flutter Test Host Debug

## 1. 数据与口径

- 使用确定性生成的 10,000 根 BTCUSDT 一分钟不可变 Kline。
- 每个场景预热 5 次；全量计算记录 30 个样本，末项更新和缓存命中各记录 100 个样本。
- 增量场景包含 `KlineStore.update`、新快照变更范围检测、指标增量计算、结果校验和缓存写入的完整路径。
- 基准指标为单序列 close 透传，用于测量协议与缓存框架开销；P3-03 迁移真实多序列/递归公式后必须分别补测。
- P95 采用样本排序后向上取整索引；RSS 只作为同一 Host Debug 进程中的粗略观测。

## 2. 结果

| 场景 | P50 | P95 | P99 | 预算/结论 |
| --- | ---: | ---: | ---: | --- |
| 全量计算 10,000 根 | 299 μs | 582 μs | 1,130 μs | 协议基线 |
| 最后一根 Store + 指标增量 | 607 μs | 1,202 μs | 7,881 μs | P95 ≤ 8 ms，通过 |
| 精确缓存命中 | 3 μs | 5 μs | 51 μs | 通过 |

同一缓存加入 6 个 10,000 点单序列结果时，进程 RSS 观测为 147,226,624 → 147,230,720 bytes，增量 4,096 bytes。该数值明显受 Dart VM 已分配堆复用影响，不能代表 retained size，也不能替代 Phase 3/5 的 6 个真实指标综合内存门禁。

## 3. 结论与限制

- 当前缓存/变更检测/注册表校验的完整末项更新路径满足 P95 8 ms 预算。
- 默认 32 项 LRU 上限阻止版本快照和指标结果无限保留。
- append/update 可走定义声明的增量路径；prepend/replace 默认全量回退，具体指标可在保证正确性的前提下单独声明支持。
- 当前数据差异检测会扫描稳定前缀；10,000 根末项更新已计入上述结果。若后续真实指标或更大数据规模超预算，可在不改变指标协议的前提下把 Store 变更元数据接入 Cache。

## 4. 复现

```bash
flutter test \
  --dart-define=RUN_INDICATOR_CACHE_BENCHMARK=true \
  test/benchmark/indicator_cache_benchmark_test.dart
```

普通 `flutter test` 会跳过此基准，避免共享 CI 主机抖动造成非确定性失败。
