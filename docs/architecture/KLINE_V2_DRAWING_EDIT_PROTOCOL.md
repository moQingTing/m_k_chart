# V2 绘图编辑协议

P7-04 提供不可变 `ChartDrawingEditor`：选择、整体移动、单锚点移动、锁定与删除都会返回新的编辑状态，不会修改既有绘图对象。锁定绘图拒绝移动、磁吸与删除；删除当前选中对象会清空选中 ID。

`isLocked` 是 schema v1 的可选 JSON 字段，未出现时默认为 `false`，保持已有绘图数据兼容。

`ChartDrawingOhlcSnapper` 在不依赖 Widget/Canvas 的前提下，将锚点先吸附到时间最近的蜡烛，再从其开、高、低、收中选择价格最近的值。P7-05 将在这些确定性编辑操作之上引入撤销/重做命令。
