iOS 模拟器无需连接实体手机。先在 Xcode 中安装 iOS Simulator 运行时并启动模拟器，然后运行：

```bash

flutter test integration_test/v2_sdk_acceptance_flow_test.dart -d <模拟器ID>
```

## 数据来源

- 默认模拟数据，无网络请求。价格路径确定，开盘时间对齐启动时刻；模拟时钟明确标为
  12 倍，每秒替换当前柱，每五秒跨过一分钟边界并新增。不能把这个加速频率当作交易所频率。
- “暂停刷新”停止自动行情和时钟；暂停期间仍可按“替换尾柱”“新增一根”做可重复检查。
- “币安实时”切到 BTCUSDT 一分钟线，首次 HTTP 请求 180 根，之后每两秒请求最新两根，
  通过新控制器 updateKline 替换/追加。不是 WebSocket，跨一分钟边界才正常出现新柱。
- 真实网络失败会明确提示，不会自动用模拟行情冒充实时结果。切回模拟、后台、暂停或退出
  页面后，旧请求即使返回也不会写入新会话。默认币安源现在通过可取消请求尝试中止
  底层 HTTP；未做公网断连测量，自定义源若未实现取消契约仍只丢弃旧结果。
- 此页行情前后台与模拟时钟由验收宿主管理；显示倒计时由候选 KChart 管理。
  仍不能据此认定正式公共 Widget 的生命周期已完成设备验收。

## 检查顺序

1. 模拟模式先暂停：主副图参数文字应为普通字体、透明背景，靠左上下居中；主图显示 EMA
   和 SUPERTREND，副图显示成交量。数据不得进入参数栏。
2. 点击主图和副图：十字线/数值/时间和信息面板出现；命中左半边时信息面板靠右，反之靠左。
   主副图之间的选中时间盖住普通刻度；副图数值使用副图格式。
3. 保持选中，手动替换和新增：计数增加，选中身份、十字线和面板仍在。恢复自动刷新后连续
   观察至少三次新增；已选柱被替换时，信息字段应更新。
4. 左右拖动/松手惯性应取消选中；双指缩放应保留选中。网格和时间跟随数据；进入历史后
   点击最新价箭头回到最新，不能同时误弹信息面板。尝试把最新柱滑到最左侧。
5. 在信息面板上开始拖动，仍应能操作图表。旋转设备及小屏横屏时检查溢出、参数遮盖、选中
   坐标错位；验收页在可用高度太小时允许外层纵向滚动。
   打开“图表设置”，修改 EMA/SUPER/VOL/MACD/RSI/KDJ 等周期或倍数；非法值应在弹窗内提示，
   合法值保存后图例、量程和线条应更新，原行情和浏览位置不应被重置。
   再打开 SAR：把初始加速改为大于加速上限，应提示关联约束且不提交；增大上限后可保存。
6. （可选 Demo 演示，非库发布门槛）切到币安，确认页面标明真实来源并观察尾柱替换；网络可用性、
   跨真实分钟边界和断线后的恢复属于示例数据源/宿主应用验收，不影响本库以模拟数据验证替换与追加。
7. （可选宿主集成检查，非库发布门槛）应用后台/前台、路由切换及数据源替换由宿主决定如何暂停
   和恢复请求。本库只检查 Widget 自身生命周期：卸载后无时钟帧、监听通知或异常回调。
