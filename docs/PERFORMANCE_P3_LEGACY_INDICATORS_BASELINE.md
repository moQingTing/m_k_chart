# m_k_chart 2.0 Phase 3 Legacy 指标迁移性能基线

> 任务：P3-03  
> 日期：2026-08-25  
> 环境：macOS、Flutter 3.44.0、Flutter Test Host Debug

## 1. 数据与口径

- 确定性生成 10,000 根 BTCUSDT 一分钟 Kline。
- 同时计算 MA、EMA、BOLL、SAR、VOL、MACD、KDJ、RSI、WR、OBV 十类迁移指标。
- 全量计算预热 5 次、记录 20 个样本；末项更新预热 5 次、记录 50 个样本。
- 末项场景包含 Store 更新、变更范围检测、十个指标增量计算、状态/Series 校验和缓存提交。
- 每个指标另建 Store/Cache 记录 50 个末项样本，并对每项执行 P95 ≤ 8 ms 门禁。

## 3. 优化证据

首次迁移仅使用全量回退时，十指标末项更新 P95 为 68,146 μs。加入递归计算状态后仍因每次复制完整 Series，P95 为 32,745 μs。最终采用写时复制的不可变序列，稳定前缀共享、变更项稀疏覆盖，P95 降至 1,942 μs，相比初始全量回退下降约 97.1%。

写时复制覆盖达到 512 项后自动物化；单测连续更新 520 次，验证结果正确、列表不可写且不会形成无限代理链。

## 4. 兼容口径

- 新结果在 Phase 0 的 29/59/99 三个索引与 24 条 legacy 序列逐项对照，容差 `1e-9`。
- WR 保留旧实现实际使用的 15 根窗口，KDJ 保留 14 根窗口，BOLL 保留总体标准差除以 20 的口径。
- 不足周期由 legacy 实体占位 `0` 改为 `null`，符合 P3-01 协议，不属于公式漂移。
